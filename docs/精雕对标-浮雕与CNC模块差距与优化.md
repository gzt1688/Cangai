### 1.3 浮雕后续路线图（按价值排序）

1. **纹理叠加 / 纹理曲面库**：把已生成的纹理场作为可命名资产（序列化到模型或文档级），
   支持多纹理叠加混合（对应精雕"纹理填充/纹理叠加/编辑纹理曲面库"）。
2. **浮雕层合并**：多高度场模型的并/差/交（先做同 bbox 两模型合并）。
3. **网格曲面基元**：圆柱面/球状穹顶/等距面的 2.5D 起浮雕（高度场直接生成，
   无需真 3D 网格）。
4. **笔刷库持久化**：笔刷参数保存/加载（对齐精雕笔刷库）。
5. **2D 曲线投影到网格曲面 / 展平映射拼合**：依赖真 3D 曲面表示，需先升级
   模型数据层（当前为 2.5D 高度场），列为大版本项。

### 2.3 CNC 后续路线图（按价值排序）

1. **曲面清根加工族**（单笔/多笔/环切/交线清角）：高度场/网格上按刀具半径做
   残料检测（本次 `rest_material_mask` 已提供核心算法）→ 生成清根刀路。
2. **残料补加工策略**：以 `rest_material_mask` 结果为加工域，复用分层区域粗加工
   生成补刀路（参考"当前残料模型"参数）。
3. **等高外形精加工**：按 Z 分层切片网格轮廓（复用 marching squares 闭环提取）。
4. **路径编辑三件套**：路径反向 / 路径连接 / 路径排序（对已生成刀路折线的纯几何操作）。
5. **环绕等距 / 径向放射 / 曲面流线**：偏移与参数线族策略（依赖网格拓扑）。
6. **夹具/刀柄碰撞检查**：碰撞检查目前仅行程/毛坯/切深；补 ClampPlate/SideClamp
   与刀柄扫掠体求交。
7. **4/5 轴**：目前为占位；建议先做四轴旋转加工（回转台 + 刀轴摆动简化为
   分度定位），五轴联动需 RTCP 后处理，列为大版本。
8. **DRL(Excellon) 输入 / .cl 刀位文件 / FANUC 方言**：后处理扩展。
